Welcome to our assignment repository where we will demonstrate our understanding of basic Git best practices as well as our ability to train a regression model using the California Housing Dataset.

## Synopsis
This project loads the California Housing dataset, splits it into training, validation, and test sets, standardizes the feature data, and trains an MLPRegressor with early stopping enabled. The workflow includes setting custom hyperparameters, evaluating model performance, and saving actual vs. predicted scatter plots for both training and test results.

## Features
- ⚙️ Data split: train / validation / test  
- 🧠 Neural network regression via MLPRegressor with early stopping  
- 📈 Saved plots: actual vs predicted for train and test
